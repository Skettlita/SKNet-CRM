# Requerimientos generales
SKNet vende suscripciones a ISP; los ISP administran abonados. Plataforma: empresas, planes versionados/configurables, trial Bs 0 sin vencimiento, límites y features, suscripciones, cobros, pagos, comprobantes, soporte, usuarios, roles, auditoría. CRM: clientes con varios contactos, direcciones, sitios, servicios y contratos/documentos, notas/tareas/historial. Sin leads ni pipeline comercial. Servicios PENDING/ACTIVE/SUSPENDED/CANCELLED, acceso PPPoE/DHCP/estático/otro, IP fija/dinámica separada, usuario PPPoE, MAC si corresponde, router de acceso, IP de servicio informativa y distinta de IP de gestión del dispositivo. No automatizar sesiones PPPoE ni DHCP en V1.
Dispositivo lógico con rol NODE/INTERMEDIATE/ENDPOINT, IP gestión única dentro de collector, no global. Infraestructura sin cliente/servicio es válida. Producto modelo vs activo físico serial/código/propiedad/ubicación vs dispositivo lógico; inventario almacenes, ubicaciones, movimientos y asignaciones, stock transaccional. Ticket OPEN/ASSIGNED/IN_PROGRESS/RESOLVED/CLOSED/CANCELLED, resolución antes de cierre, OT pendientes bloquean cierre, cancelación justificada, reapertura con historial, varios técnicos. Cobranza cargos mensuales por servicio activo, fecha generación/vencimiento configurable, pagos parciales, asignaciones, recibos internos no factura fiscal, ajustes auditados. Estado financiero al día sin saldo, pendiente saldo no vencido, moroso saldo vencido; independiente de estado administrativo, no suspensión automática. Prorrateo, suspensión/cobro y devolución activos pendientes para fase posterior, no inventar reglas. SaaS billing y soporte independientes de ISP. Auditoría antes/después sin secretos. No borrado físico de historial.
MVP definido en MVP.md: auth, SaaS planes/empresas, CRM básico, provisioner con NAT RouterOS propia, ICMP, incidentes y ticket automático básico. Resto como horizonte, no implementación completa exigida ahora. SNMP CPU/RAM/temp/uptime/tráfico, OIDs/vendor, API cliente, traps/syslog, NetFlow, topología y Telegram futuros. Features no implementadas nunca se presentan habilitadas.
