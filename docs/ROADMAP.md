# Orden de implementación
0. Inspeccionar referencia, entorno y DDL. Registrar riesgos y estado real. 1. Fundación: Compose, PostgreSQL, Alembic, FastAPI health, frontend Vite y layout compartido, pruebas y gitignore. 2. Auth, ámbitos, roles, planes, signup y CLI admin; probar aislamiento. 3. Administración de la plataforma SaaS. 4. CRM empresarial, dispositivos y configuración ICMP. 5. Provisioner, pools, Docker y API RouterOS propia; wizard y prueba WireGuard real. 6. Collector ICMP, API, heartbeat, mediciones, incidentes y soporte automático. 7. Validación de dashboards operativos, pruebas de integración y despliegue TEST. 8. Después del MVP: módulos avanzados CRM, billing/inventory/OT y futuras tecnologías según requisitos. No saltar seguridad por tiempo. Priorizar demostrar dos ISP misma IP, caída de uno sin afectar otro. Mantener docs/IMPLEMENTATION_STATUS.md con tareas implementadas, tests ejecutados, resultados, comandos y bloqueos. Si falta tiempo, entregar una porción funcional verificable y reportar pendiente.
